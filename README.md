# Padrão Strategy

Exemplo do padrão comportamental **Strategy** aplicado ao cálculo de frete.
A entrega não sabe calcular o frete sozinha: ela recebe uma estratégia de cálculo
(PAC, Sedex ou retirada na loja)

## Conteúdo do repositório

- **Código-fonte** do exemplo implementando o padrão Strategy (cálculo de frete).
- **Casos de teste** (JUnit) cobrindo cada estratégia, a troca em tempo de execução e casos de borda.
- **Diagrama UML** das classes, em formato de imagem.
